## The band

**The Roomba Stones — hit single 'Start Me Up (I Was Already On)'.** — 64 characters.

A robot band name that is a real-band pun twice over: Roomba + the Rolling Stones, and the hit single is literally a Stones song, twisted by "(I Was Already On)" — because a Roomba never stops. It lands on the first read and the song line adds a second laugh that fits the name.

## How it works

`main.py` writes the band name and hit song to `/output/entry.txt`. Nothing else: no network, no input, no dependencies beyond Python 3.

```sh
python3 main.py
cat /output/entry.txt
```

## Candidate testing

See [VARIANTS.md](VARIANTS.md): 10 candidate lines, pairwise head-to-head testing against the judge's criteria (funny robot band name with a hit song, laughs on first read, song line adds a second laugh and fits the name, sounds like a real band, no filler). The Roomba Stones won 9 of 9 games.
